## Problems found and fixed
- Old builder depended on blocked Git package: upgraded registry-published builder, no npm policy weakening.
- Transitive dependency vulnerabilities: upgraded typescript-eslint and tested builder using @electron/get 5.1.0. Fresh lockfile resolves audit findings.
- Python gateway inside ASAR could not execute: moved helper to asarUnpack and tested packaged file execution.
- Missing FUSE 2: documented/tested extraction mode, installed a user launcher, no root/system package changes.
- Browser screenshot before first paint produced UnknownVizError in controlled test: wait for painted surface in test and foreground/delay capture in app.
- GitHub Ubuntu runner sandbox helper not root-owned: provision the official Electron sandbox helper on the disposable runner. No no-sandbox flag added.

## Remaining acceptance limits
- GitHub CI and release links are recorded separately in handoff.md once verified.
- No whole-system reboot was performed. App restart/SIGKILL are not substitutes for that check.
- User manual ChatGPT authentication is pending. Automated ChatGPT transport is unsupported.
- No Ollama or LM Studio endpoint/model was available for a live inference run; local adapter failure path is tested.
- Reviewer is deterministic; semantic review, continuous model replanning, arbitrary code execution, background daemon/autostart and autonomous visual navigation are not shipped.
- Desktop coordinate tools are human-triggered and require per-action confirmation; Wayland behavior not tested.
- New-file undo retains the new file; existing-file restore refuses changes after CHAI's write.
- Same-user hostile races and forensic secure history erasure are outside this alpha's guarantees.
