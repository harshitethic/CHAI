# Contributing to CHAI

Thanks for contributing. This is an execution-capable desktop tool: correctness, transparency, and security come before feature count.

## How to contribute

1. Open an issue describing a bounded improvement and how it will be tested.
2. Create feature branch; include tests for state/tool/provider changes.
3. Run the actual repo's lint, typecheck, unit, E2E and package smoke where relevant.
4. For security-impacting changes, describe trust-boundary changes and permission impact.
5. Add screenshots made from **CHAI**, not unlicensed third-party UI, if UI changed.
6. Use real CI/test evidence and keep secrets/browsing profiles/private files out of Git.

Avoid fabricated badges, synthetic statistics, stealth browser automation, provider rate-limit bypass or privilege escalation. Never copy protected logos or another product's layout pixel for pixel.
